ИИ-помощник: система

Любой ответ помощника собирается по одной схеме из четырёх мест. Других мест для кнопок и блоков нет. Разработчик получает ответ модели в виде данных (ниже) и рисует его этими деталями – новая задача помощника не требует нового дизайна.

1. Схема ответа одна для всех ответов

1Метка – только если нужно решение или что-то изменилось
2Текст – 1–3 коротких абзаца
3Блок – один: список товаров, список вариантов, итог или шаги
4Действия – 0, 1 или 2 кнопки на всю ширину, одна под другой
МестоПравило
1. Метка«Уточнение» – надо выбрать; «Подтверждение» – да / нет; «Готово» – изменил комнату; «Не выполнено» – не смог. Нет метки – просто ответ.
2. ТекстВсегда есть. Вопрос – в конце текста, а не отдельной строкой после блока.
3. БлокНе больше одного. Внутри – строки одной высоты; больше 4 строк – последняя строка «Ещё N…», раскрывает список здесь же.
4. ДействияТолько у последнего ответа. Всегда на всю ширину карточки, одна под другой, на всех экранах. Первая – бирюзовая, если это решение; вторая – белая. Выбор из вариантов – не кнопками, а строками блока.
НельзяМаленькие кнопки внутри ответа, кнопки в ряд, ссылки-действия, подсказки-чипы внутри ответа (чипы – только в приветствии).

2. Данные для разработчика

Модель возвращает ответ в таком виде; интерфейс рисует его по схеме выше. Вариант всегда = заголовок + подпись + действие, которое выполнится при нажатии.

{
  "kind": "ask",               // ask | confirm | done | fail | null
  "text": "Окно 120 см не помещается…",
  "block": {
    "type": "options",         // products | options | summary | steps
    "items": [
      { "title": "Окно 90 см на стену 1",
        "subtitle": "Встанет между дверью и углом",
        "action": { "op": "add_window", "wall": 1, "w": 90 } }
    ],
    "more": 0                  // сколько ещё скрыто под «Ещё N»
  },
  "actions": [                 // 0–2
    { "label": "Удалить 2 окна", "primary": true, "action": {…} },
    { "label": "Не удалять",     "action": null }
  ],
  "undo": true                 // «Вернуть как было» – отменяет изменения этого ответа
}
Тип блокаСтрокаНажатие
productsфото, название, количество или метка, суммапримерка или карточка товара
optionsзаголовок, подпись, стрелкавыполнить action варианта
summaryдо 4 строк «название – сумма», итогнет; кнопка «Открыть смету»
stepsзначок «сделано / не сделано», шаг, причинанет

7. Окно на телефоне два положения

Стандартная шторка, как в картах: ручка сверху – потянуть вниз или нажать → полэкрана (план виден, приближен к поверхности с полями 10–15 %); потянуть вверх → весь экран. Других кнопок для этого нет. На полэкрана чат прокручивается, ответ и действия те же. На компьютере – вкладка в правой панели, на планшете – окно справа по высоте холста.

9. Текст

От первого лица в мужском роде («Положил», «Сделал»), коротко. Главная кнопка – действие с предметом («Удалить 2 окна», «Применить», «Добавить в смету»). Отказ – «Не …» по смыслу. Отмена – «Вернуть как было». Цены «23 760 ₽». Без «—», «·» и служебного текста.
